# 顾好家社区服务 APP · 用户端交互原型

可点击的高保真 HTML 原型，覆盖社区服务 APP 用户端全部业务页面。

也可直接克隆后用浏览器打开 `顾好家APP用户端-交互原型.html`（单文件、零依赖）。

## 原型概况

- 形态：单文件 HTML（内联 CSS / JS，无外部依赖）
- 设计语言：iOS 系统风格（分组列表、SF Symbols 风格线性 SVG 图标、薄荷绿 + 珊瑚橙配色）
- 页面数：约 88 个
- 交互：支持页面路由跳转、底部 Tab 切换、分段控件数据筛选、底部弹窗选择

## 主要模块

| 模块 | 说明 |
| --- | --- |
| 注册登录 | 手机号登录、验证码、微信授权、隐私协议 |
| 业主认证 | 小区 / 楼栋 / 房号选择、证件上传、认证状态 |
| 首页 | 服务宫格、通知栏、轮播、快捷入口 |
| 健康小屋 | 健康档案、检测报告（日报 / 周报 / 月报 / 年报 / 24小时 / 近七天 / 近30天）、趋势图表 |
| 服务预约 | 陪诊、托管、报餐三类服务的下单流程 |
| 物业服务 | 报修、投诉、缴费、物业系统跳转 |
| 生活帮手 | 家政、维修等第三方服务 |
| 社区 | 活动报名、社区贴吧、通知公告、资讯 |
| 订单中心 | 三套订单列表、结算、评价、退款 |
| 我的 | 个人资料、家庭、账单、管家、手环、钱袋子、人力资源、设置 |

## 交互说明

- 底部 Tab 仅在 4 个一级页（首页 / 社区 / 订单 / 我的）显示
- 所有分段控件（Tab）切换均为真实数据变化
- 所有下拉选择均为底部弹窗（sheet），不跳转页面
- URL hash 支持预设状态，便于截图与演示：
  - `#页面ID` 直接打开指定页
  - `#healthReport&_chip=healthReport=4` 预设分段选中项
  - `#页面ID&_pick=key` 打开底部弹窗
